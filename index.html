Connect Spotify

Uses my Spotify developer app. App owner needs Spotify Premium, and anyone who uses it must be added to the app's user list.

How to set up the Spotify app
  1. Go to developer.spotify.com/dashboard and choose Create app.
  2. Under redirect URIs, add the address shown above, exactly as written.
  3. Under APIs used, choose Web API, then save.
  4. Open the app's settings and copy the Client ID into the box above. You don't need the client secret.

How to export from Apple Music
  1. In the Music app on a Mac (or iTunes on Windows), select the playlist in the sidebar.
  2. Choose File, then Library, then Export Playlist.
  3. Save it as Unicode Text or XML. Either works.
